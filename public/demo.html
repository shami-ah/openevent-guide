OpenEvent Guide

AI-powered interactive onboarding.
One script tag. One boot call. Done.

1

Chat

Users ask questions in plain language. The AI answers or guides them through the feature live.

2

Browser Control

The guide navigates, highlights, clicks, and fills fields in the user's real browser.

3

Subtitles

Every action is explained with on-screen subtitles so users learn as they go.

4

Multilingual

Detects the user's language automatically. English, German, French.

Integration

Add two lines to your app. Every user gets the guide automatically.

<!-- Add before </body> -->
<script src="https://guide.openevent.io/sdk.js"></script>
<script>
  OpenEventGuide.boot({
    user_id: "usr_123",
    email: "thomas@venue.com",
    name: "Thomas",
    team: "MAD Productions"
  });
</script>
